# Species Visual Styles

Silhouettes must be recognisable per species at strategy zoom. Use these as starting points.

| Species | Shapes | Proportions | FACTION panels | Engines | Notes |
|---|---|---|---|---|---|
| **Humans** (`human`) | Boxes, wedges, hex cylinders; hard edges, small bevels | Long slabs, armoured prow, superstructure aft of centre | Big side armour plates | Clustered, chunky, orange glow | Visible barrels and plating: "built to take a hit" |
| **Vess'kar** (`vesskar`) | Stretched spheres, thin fins, 10+ segment cylinders | Slender, needle-like, elegant | Swept fins / wings | Single slim nozzle, blue glow | Beautiful and fragile-looking; few greebles |
| **Krothi** (`krothi`) | Spheres + rotated wedges as spikes, asymmetric allowed | Hunched, organic, clustered pods | Carapace plates | Many small nozzles, sickly yellow | Cheap, numerous: keep tri counts low |
| **Ohlan** (`ohlan`) | Big boxes, cargo pods (cylinders along X), rings | Bulky, wide, modular containers | Pod bands / logo plates | Twin large, green glow | Merchant look even on warships |
| **Thessari** (`thessari`) | Spheres, domes, rounded cylinders | Compact, rounded, shielded cores | Dome caps | Soft violet glow, hidden | Defensive, "shell" feeling |

## Class silhouettes (all species)

| Class | Silhouette cue |
|---|---|
| Scout / corvette | Dart or needle; small; one or two engines |
| Frigate | Corvette + point-defence blisters (hardpoints `D`) |
| Destroyer | Longer dart with a torpedo/prow feature |
| Cruiser | Slab + raised superstructure + side armour |
| Battlecruiser | Long cruiser with a big forward mount (`W L`) |
| Battleship | Fortress: wide, tall, many mounts, heavy aft block |
| Carrier | Flat or split deck with hangar mouths (`H` hardpoints) |
| Freighter | Spine + container pods; FACTION on pods |
| Station | Hub + ring/arms + docking markers; no forward direction |
